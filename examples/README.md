# Examples

The JSON files in `configs/` demonstrate the material configuration schema. They do not include crystallographic coordinates.

Obtain CIF files from the original paper's supporting information, an author or institution repository, or a traceable crystallographic database. Verify that the structure matches the cited material and that its terms permit your intended use.

To run an example, copy the JSON file into an asset project, update its citation and validation requirements to match the selected CIF, and pass it to each workflow command with `--config`.
